Citadel.

Your own command center for projects, terminals and AI coding agents.

Close the browser, restart the panel, switch machines: your sessions keep running. Runs on a VPS, a Mac or a spare laptop, with 512 MB of RAM.

curl -fsSL https://raw.githubusercontent.com/maksymhs/Citadel/main/install.sh | bash

Linux and macOS. Windows via WSL2. On Debian/Ubuntu add sudo before bash to install the system service.

Features

Terminals

Persistent sessions

xterm.js, node-pty and tmux. Sessions survive closing the browser or restarting the panel. Phone-friendly, with on-screen keys and clipboard copy.

Projects

Projects & Git

Register, create, import and clone repositories with live branch status. Connect GitHub or GitLab and clone private repos in one click.

Secrets

Credential vault

One AES-256-GCM encrypted store for git tokens, env vars and SSH keys. Terminals get them at spawn; agents read them on demand with citadel-creds.

Machines

Paired Citadels

Pair machines with a QR code and switch between them from one URL. Survives rotating Cloudflare Quick Tunnel addresses and propagates updates.

Health

Monitoring & alerts

CPU, memory, disk, latency and 24 h / 7 d availability for every machine. Alerts to webhook, ntfy or Telegram, including security events.

Orchestration

Distributed task mesh

A pull-based work queue so one orchestrator agent can split work across nodes, with a dependency-free MCP server.

Host

Files & disk cleanup

Browse and edit the host filesystem, analyse disk usage and run quick cleanups with per-item selection.

Insight

Observability

Event trace plus periodic resource samples, a live sparkline, a filterable timeline and JSON/CSV export.

Also: a command palette (Ctrl/Cmd+K), light, dark and system themes, an installable web app, and optional domain publishing through Caddy with automatic HTTPS.

How it works

A small Node.js service that owns your terminals, so the browser is just a window onto them. Lean by design: Fastify, SQLite in WAL mode, a plugin system with fault isolation, and a frontend with local vendor bundles and no CDNs.

Secure by default

Local-only
Listens on 127.0.0.1 unless you opt in to LAN or a tunnel.
Setup code
The first admin account needs a code only someone with shell access can read.
Strict sessions
HttpOnly, SameSite=Strict cookies, WebSocket origin validation and path-traversal prevention.
Audit log
Every sensitive action is recorded, with credentials redacted.
Not root
The service runs unprivileged; every extra capability is an explicit installer flag.

Citadel does not sandbox projects from each other, and a terminal is a shell with the service account's rights. Read the limitations before exposing it.

Quick start

The installer prints the panel address, a setup code and a QR. Open the address and create the administrator account.

curl -fsSL https://raw.githubusercontent.com/maksymhs/Citadel/main/install.sh | bash

Prefer to look first? The script is short and supports --check-only to preview what it would do.

The citadel CLI

citadel status          # service, version, panel URL and health
citadel qr              # one-time QR to pair another Citadel
citadel update          # update to the latest version
citadel tunnel          # global URL via a Cloudflare Quick Tunnel
citadel logs            # follow the service logs
citadel doctor          # read-only host, network and Citadel diagnosis
citadel repair          # allow-listed recovery actions
