CASE STUDY / DEVELOPER TOOLS

Citadel

A command center for the projects, terminals and agents that otherwise live across separate tools.

View source Product tour
  • Node.js
  • Fastify
  • SQLite
  • tmux

The context

For developers running projects and AI coding agents on their own machines, a browser tab should be a window into the work, rather than the thing keeping it alive. Citadel brings those workspaces, terminals and machine health into one self-hosted interface.

Decisions & tradeoffs

Persistence below the UI

tmux keeps sessions alive independently of the browser. Node.js and Fastify expose the workspace, while SQLite stores application state.

A small deployment footprint

The documented minimum is 512 MB of RAM, with 1 GB recommended for AI agents. Optional services add capabilities without becoming baseline requirements.

Explicit operational boundaries

A terminal runs with the service account’s rights; Citadel does not sandbox projects from each other. The product documentation makes that boundary explicit.
