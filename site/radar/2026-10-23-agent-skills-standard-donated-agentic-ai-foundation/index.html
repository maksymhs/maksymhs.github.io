Agent Skills standard donated to the Agentic AI Foundation

23 Oct 2026 · 4 picks

Anthropic has donated the Agent Skills open standard to the newly formed Agentic AI Foundation, a move that could shape how agentic tooling interoperates across platforms. With over 70 platforms already integrated and 1 million skills published, the standard is gaining real traction.

  1. Donating Agent Skills to the Agentic AI Foundation

    Anthropic · 22 Oct 2026

    According to Anthropic, the Agent Skills standard was published in December 2025 and has since been integrated by more than 70 agent platforms, including ChatGPT, Cursor, GitHub Copilot, and VS Code, with 1 million skills published and nearly 280 million installed. The donation includes the Agent Skills name and logo, the GitHub organization, and the agentskills.io domain, and will be maintained by engineers from Anthropic, Google, OpenAI, and other companies as individuals, with David Soria Parca and Mahesh Murag named as Lead Maintainers. I would watch how transparently the foundation handles community input and decision-making, since the value of any open standard depends on trust and neutrality. For backend teams building or integrating agentic workflows, this is the kind of cross-platform compatibility layer that could reduce vendor lock-in, but I would verify how quickly new contributions are reviewed and whether the governance model stays truly open as adoption grows.

  2. OpenAI donates Open Responses, its spec for a common LLM API, to the Agentic AI Foundation

    The New Stack · 22 Oct 2026

    OpenAI has also donated Open Responses, its specification for a common LLM API, to the Agentic AI Foundation, according to The New Stack. This move is intended to promote interoperability among AI models, and the foundation will maintain and further develop the spec. It is worth watching whether this leads to broader compatibility across model providers.

  3. Presentation: Actors for Agents: Patterns for Production AI

    InfoQ · 22 Oct 2026

    Manju Rajashekhar presented 'Actors for Agents: Patterns for Production AI' at InfoQ, drawing on his experience scaling Twitter's caching systems and leading AI functions at Etsy after Blackbird AI's acquisition. The talk applies the actor model to production AI agents, addressing state ownership, message passing, and supervision boundaries. This is a useful lens for teams trying to move agentic workflows beyond demos into resilient architecture.

  4. Allocating Off-Heap Memory: Typically 6-18x Faster in JDK 28

    Inside Java · 23 Oct 2026

    According to Inside Java, the Foreign Function and Memory API in JDK 28 will reduce off-heap memory allocation latency by up to 90% on Windows, Mac, and Linux, with no source code changes required. The improvement comes from each platform thread maintaining a small cache of native-memory pools, with virtual threads borrowing from their carrier thread. Teams doing heavy native interop on the JVM should find this a meaningful performance boost.
