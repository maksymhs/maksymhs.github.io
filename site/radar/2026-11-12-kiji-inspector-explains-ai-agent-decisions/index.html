Kiji Inspector explains AI agent decisions

12 Nov 2026 · 4 picks

Dataiku's Kiji Inspector uses Sparse Autoencoders to explain AI agent decisions, while AWS releases a local emulator for its services.

  1. Presentation: Opening the Black Box: Critical Explainability for AI Agent Tool Selection with Kiji Inspector

    InfoQ · 12 Nov 2026

    Hannes Hapke, Director of Engineering at Dataiku, presented Kiji Inspector at QCon AI. According to InfoQ, this open-source tool uses Sparse Autoencoders to understand how AI agents make decisions, forcing the model to use a small set of features, with about 95% of features set to zero. The Kiji Inspector project combines several techniques to help understand model activations in production. Understanding why an AI agent chooses a particular tool or action is crucial for maintaining trust and ensuring compliance, especially in regulated industries like banking. I would verify the tool's accuracy and integration capabilities before adopting it in any AI-assisted engineering projects.

  2. aws-emulator

    Simon Willison · 11 Nov 2026

    AWS released an official emulator called aws-emulator, allowing local testing of AWS services without a paid API key. According to Simon Willison, the emulator is written in Rust and currently requires Docker to run on macOS or Windows. This could be a game-changer for developers looking to reduce costs and improve the speed of development cycles.

  3. Gemini Decisions API

    Simon Willison · 11 Nov 2026

    Google released the Gemini Decision 1 API, supporting text, images, audio, video, and PDFs. According to Simon Willison, the API is priced at 10 cents per million input tokens, with free output. This API could be useful for integrating multimodal decision-making into applications, but its performance and accuracy should be verified before adoption.

  4. Build autonomous AI agents with Amazon Bedrock and Spring AI

    AWS Machine Learning · 12 Nov 2026

    AWS Machine Learning published a guide on building autonomous AI agents with Amazon Bedrock and Spring AI. The guide demonstrates building a single-agent travel assistant and a multi-agent document processing system. This approach could provide a scalable and secure way to integrate AI capabilities into JVM-based applications, but its scalability and security features should be evaluated carefully.
