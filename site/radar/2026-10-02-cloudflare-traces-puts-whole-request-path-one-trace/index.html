Cloudflare Traces puts the whole request path in one trace

2 Oct 2026 · 4 picks

Tracing that starts at the edge and continues into your origin over W3C and OpenTelemetry standards closes a common blind spot.

  1. Introducing Cloudflare Traces: follow requests through our entire platform

    Cloudflare Blog · 2 Oct 2026

    Cloudflare Traces, in open beta, extends tracing beyond Workers to security rules, cache decisions, routing and origin handling, so a single trace covers the whole request. The example that sells it: a cache miss that spent 527 ms of a 539 ms response waiting on origin, visible on one timeline. It accepts and forwards W3C traceparent headers and exports OpenTelemetry spans over OTLP to any compatible backend, with a baseline sampling rate (such as 1%) that Trace Rules can override per hostname or debug header. Note the pricing: it moves to ingestion and retention from December 1, 2026, with 0.5 GB per day on the free plan. Observability is the part of backend work I care about most, and a trace that starts at the edge and ends in the database tells you where the time went, instead of each team staring at its own logs.

  2. 8 major updates to Cloudflare Observability

    Cloudflare Blog · 2 Oct 2026

    Cloudflare also launched eight updates that bring logs, traces, analytics, alerts, dashboards, querying and telemetry export into one observability platform, with simpler and more predictable pricing. Worth a look if you already run workloads on Workers and want fewer tools to correlate.

  3. Spring AI Modular RAG and TypeSafe Jev: Retrieve More, Keep Only What Answers

    Spring Blog · 2 Oct 2026

    A Spring blog post on modular retrieval-augmented generation with Spring AI. Worth a read if you are adding retrieval to a Java service and want to see how the Spring team structures it.

  4. JEP targeted to JDK 28: 540: Simple JSON API (Incubator)

    Inside Java · 2 Oct 2026

    JEP 540, a Simple JSON API (Incubator), is targeted to JDK 28. A JSON API in the JDK could remove one dependency for small services and tools, but it is incubating, so I would watch it rather than adopt it yet.
