AWS treats digital sovereignty as an architecture question

5 Oct 2026 · 2 picks

The new Well-Architected lens turns sovereignty into five design questions, a useful framing for regulated European workloads.

  1. Announcing the AWS Digital Sovereignty Lens for the Well-Architected Framework

    AWS Architecture Blog · 5 Oct 2026

    AWS launched the Digital Sovereignty Lens for the Well-Architected Framework: 21 questions and 37 best practices across four pillars (operational excellence, security, reliability and performance efficiency). It frames sovereignty as architecture with five questions: where is the workload located, who can reach it, will it keep working when conditions change, can it be transferred elsewhere, and can you prove the controls are in place. It points to SCPs, RCPs, AWS Config and CloudFormation Guard for enforcement, and recommends reviews with engineering, legal, compliance and security in the same room. I work on a bank launching in Germany, where local regulation shapes the domain model and configuration, and the 'can you prove it' question is the one teams tend to underinvest in. Evidence has to be designed in, not collected at audit time.

  2. Making Arena.ofConfined() Even Cheaper in JDK 28

    Inside Java · 5 Oct 2026

    Inside Java describes pooled confined arenas in JDK 28, which significantly improve the cost of short-lived native allocations. Relevant if you use the Foreign Function and Memory API for off-heap work in hot paths.
