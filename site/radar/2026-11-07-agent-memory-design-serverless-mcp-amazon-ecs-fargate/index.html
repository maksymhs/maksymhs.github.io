Agent memory design and serverless MCP on Amazon ECS Fargate

7 Nov 2026 · 4 picks

Today's radar covers the design of agent memory inspired by human processes, a serverless MCP server on Amazon ECS Fargate, and new capabilities in AI agents.

  1. The components of agent memory

    Anthropic Engineering · 6 Nov 2026

    Anthropic Engineering discussed the design of memory for AI agents, drawing inspiration from human memory processes. Researchers at Letta and UC Berkeley proposed 'sleep-time compute,' where models use idle time to reorganize context, a process they call 'dreaming.' This approach aims to improve an agent's ability to retain and use knowledge over time. According to Anthropic, different versions of Claude were evaluated on the Continual Learning Bench 1.0, which measures an agent's ability to use memory for long-horizon tasks. I would check how this memory reorganization impacts the performance of AI agents in real-world applications, particularly in tasks that require sustained learning and adaptation. The ability to tag important events and store them in a memory store could be crucial for backend teams working on AI-assisted systems, as it would enable more efficient and effective knowledge retention.

  2. Gemini Omni 1.2 Flash: Fast and cost-effective with longer clips

    Google · 5 Nov 2026

    Google released Gemini Omni 1.2 Flash, which supports native 15-second video creation and multi-turn conversational editing. This version includes enhanced reference following and is priced at $0.07 per second for 720p video. This new capability could significantly impact video editing and content creation workflows.

  3. Serverless MCP server for AI agent data lake access on Amazon ECS Fargate

    AWS Machine Learning · 6 Nov 2026

    AWS Machine Learning introduced a serverless MCP server for AI agent data lake access on Amazon ECS Fargate. This server acts as a centralized gateway between AI agents and an enterprise data lake, supporting multiple agents and applications in a multi-tenant environment. The architecture enforces access control at the server layer and supports bursty AI workload patterns. This approach could improve data access and management for AI agents in enterprise settings.

  4. Taxonomy of agentic primitives in Amazon Quick

    AWS Machine Learning · 6 Nov 2026

    Amazon Quick's agents have evolved to perform actions like scheduling meetings and generating reports. The team developed a taxonomy that decomposes agentic work into four questions: When?, What?, Who?, and How?. This taxonomy aims to provide a shared definition of the primitives that agentic work is built from. This taxonomy could streamline the development and deployment of AI agents in various industries.
