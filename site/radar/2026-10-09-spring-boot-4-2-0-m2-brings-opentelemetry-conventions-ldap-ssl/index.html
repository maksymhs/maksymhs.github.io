Spring Boot 4.2.0-M2 brings OpenTelemetry conventions and LDAP SSL bundles

9 Oct 2026 · 2 picks

A milestone, not a release, but the 4.2 line is already pointing at standard telemetry configuration. Spring Cloud's new train builds on it, with a Resilience4J bump.

  1. Spring Boot 4.2.0-M2 available now

    Spring · 25 Sept 2026

    Spring Boot 4.2.0-M2 is on Maven Central. The announcement is short: it counts 141 enhancements, documentation improvements, dependency upgrades and bug fixes, and highlights two features. One is SSL bundle support for LDAP, including LDAPS for the embedded LDAP server. The other is support for OpenTelemetry semantic conventions, plus common OTLP endpoint, header and compression configuration. The post does not list the individual changes, so the release notes on GitHub are where to check the rest. The OpenTelemetry part is the one I would watch. Telemetry setup tends to end up scattered across properties, agents and custom code, and a shared configuration surface for OTLP means less glue per service and fewer differences between teams. On a platform with many services that consistency matters more than any single feature. When I built observability at Simyo it was custom AOP instrumentation feeding Grafana and Kibana, so I know how much work a standard convention would have saved. This is a milestone, so I would try it in a branch or a side service, read the release notes and wait for the GA before planning an upgrade.

  2. Spring Cloud 2026.0.0-M1 (aka Paddington) Has Been Released

    Spring · 24 Sept 2026

    The new release train is built on Spring Boot 4.2.0-M2. The announcement lists Resilience4J 2.4.0 in Circuitbreaker, Feign 13.14 in Openfeign and Spring Vault 4.1.0. If you rely on circuit breakers, as I did with Hystrix at Santander, the Resilience4J bump is the line to check.
