Google's Tool Retrieval for Gemini and AWS's agent-built emulator

20 Nov 2026 · 4 picks

Google's new Tool Retrieval for Gemini and AWS's agent-built emulator are both significant steps in the evolution of AI-assisted engineering.

  1. Introducing Tool Retrieval in the Gemini API

    Google · 19 Nov 2026

    Google introduced Tool Retrieval in the Gemini Interactions API, designed to manage large tool libraries more efficiently. Tool Retrieval reduces input token counts and latency by loading parameter schemas only when needed, which is crucial for scaling agents. It works with Gemini 3.6 and later models, including all Gemini 4 models, and has no separate charge; input and output tokens are billed at the standard rates for the model you call. Tool Retrieval also supports remote MCP servers in the Gemini API. I would check how this feature integrates with existing tooling and whether it can handle the specific needs of backend systems, especially in regulated environments like banking. The ability to defer loading could be particularly useful for optimizing performance in high-traffic applications.

  2. AWS Releases a Free Local Emulator of AWS Built Entirely by Agents

    InfoQ · 20 Nov 2026

    According to InfoQ, AWS released AWS Emulator, a free local implementation of over 200 of its services, written entirely by autonomous AI agents. This emulator, dedicated to the public domain, could be a valuable tool for developers looking to test AWS services locally.

  3. Google Donates Agent Substrate and gVisor to the CNCF to Secure AI Agents at Scale

    InfoQ · 20 Nov 2026

    According to InfoQ, Google donated Agent Substrate and gVisor to the Cloud Native Computing Foundation to address challenges in running autonomous agents at scale. These components aim to improve the efficiency and security of AI agents, which is crucial for backend engineering.

  4. Genie 4 is now available

    Google DeepMind · 18 Nov 2026

    Google DeepMind released Genie 4, which allows real-time editing of environments using natural language and includes native audio that adapts in real time. This tool could be useful for creating and testing complex environments, but it is currently limited to Google AI Ultra subscribers.
