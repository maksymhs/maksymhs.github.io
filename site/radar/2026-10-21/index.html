TypeScript compiler ported to Rust for speed and efficiency

21 Oct 2026 · 4 picks

Cloudflare and partners have ported the TypeScript compiler to Rust, achieving significant performance improvements.

  1. Introducing tsrs: A port of TypeScript to Rust

    Cloudflare · 20 Oct 2026

    Cloudflare, VoidZero, and Max Schwenk of Owner.com have collaborated on tsrs, a Rust port of the TypeScript compiler. This project, part of the Oxc JavaScript compiler toolchain, aims to make TypeScript faster and more memory-efficient. Early benchmarks show tsrs is up to 8x faster and uses ~70% less memory compared to TypeScript 7.0 with the same number of type check workers. TypeScript 7.1 beta is up to 2.5x faster than TypeScript 7.0. The benchmarks ensure fairness by comparing the same configuration. This effort is significant for backend teams working with TypeScript, as it promises substantial performance gains. I would verify the stability and compatibility of tsrs with existing TypeScript projects before adopting it, as the transition to a new compiler can introduce unforeseen issues.

  2. Introducing Amazon ECS Gateway: A fully-managed ingress solution for ECS services

    AWS News · 20 Oct 2026

    Amazon ECS Gateway simplifies ingress networking for containerized workloads by dynamically provisioning and managing necessary infrastructure. Platform teams can define organizational networking standards in a single place, while application teams opt their services in easily. This could streamline the management of containerized applications on AWS, making it worth watching for teams using Amazon ECS.

  3. Cilium 1.20 Expands Gateway API and Opens eBPF Datapath for Kubernetes

    InfoQ · 21 Oct 2026

    Cilium 1.20 expands the Gateway API and opens the eBPF datapath to third-party plugins. This release adds support for HTTPRoute external authorization, TCPRoute, UDPRoute, and ListenerSets, providing more flexibility for Kubernetes networking. I would check the stability and documentation of these new features before integrating them into a production environment.

    Habr (in Russian) · 20 Oct 2026

    The article on Habr (in Russian) discusses the transition from Java 21 to Java 25, highlighting features deprecated in Java 21 that were removed in Java 25. It includes examples compiled and run on JDK 21.0.7 and JDK 25.0.3, noting changes such as the automatic running of annotation processors and the disabling of the Security Manager. The piece contains practical examples and migration tips for Java developers, making it useful for teams planning to upgrade their Java versions.
