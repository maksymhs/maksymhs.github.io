Java Champions on GitHub Copilot: agentic workflows and virtual-thread pitfalls

26 Oct 2026 · 2 picks

GitHub Copilot is moving from autocomplete to agentic workflows, and three Java Champions share how they actually use it in practice, including one case where it helped trace a virtual-thread pinning bug.

  1. How three Java Champions put GitHub Copilot to work

    Foojay · 26 Oct 2026

    According to the GitHub Blog, Vlad Mihalcea, Patrick Baumgartner and Frank Delporte were interviewed by Julien Dubois about their real-world use of GitHub Copilot. Mihalcea uses Copilot to accelerate feature development while keeping existing coding practices intact. Baumgartner builds agentic workflows with clear requirements and task-specific verification steps. Delporte used Copilot to investigate a Pi4J hardware-input bug that traced back to virtual-thread pinning in native calls. The practical advice they converge on is to give the agent useful context, ask for evidence, review its output, and remain responsible for what ships. I would watch whether Copilot's agent mode can reliably handle multi-step refactoring across a large Java codebase without introducing subtle regressions, and I would verify its behavior against existing integration tests before trusting it with production changes.
