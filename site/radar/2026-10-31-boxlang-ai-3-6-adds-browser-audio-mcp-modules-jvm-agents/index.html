BoxLang AI 3.6 Adds Browser, Audio, and MCP Modules for JVM Agents

31 Oct 2026 · 4 picks

Ortus Solutions released BoxLang AI 3.6, extending its JVM-based productivity platform with browser automation, audio processing, and a stdio MCP client. The update is relevant as teams look for ways to embed agentic capabilities directly into existing Java stacks without spinning up separate runtimes.

  1. BoxLang AI 3.6: Your Agent Now Has Eyes, Ears, and a Voice

    Foojay · 31 Oct 2026

    According to Foojay, BoxLang AI 3.6 introduces bx-playwright 1.0 for browser automation across Chromium, Firefox, and WebKit, bx-audio 1.0 with 83 audio functions on the JVM, and a stdio MCP client for communicating with any MCP server via stdin/stdout. It also adds MariaDBVectorMemory for vector storage on MariaDB 11.7+, updates default models to gpt-5.6-luna, claude-sonnet-5, and openai/gpt-oss-20b, and raises the default timeout from 45 to 90 seconds. Security features include auto-fencing for ${ context } to prevent prompt injection and OutputGuardMiddleware to redact secrets and PII from model reasoning. I would verify whether the MCP client supports the same authentication and transport flexibility I expect from native implementations, and I would check how the 90-second timeout interacts with long-running browser or audio tasks in production. The MariaDB vector store is interesting for teams already on MariaDB 11.7+, but I would want to benchmark it against dedicated vector databases before committing.

  2. Google Discloses PageBreak AI Security Agent That Found 500+ XSS Bugs

    InfoQ · 31 Oct 2026

    According to InfoQ, Google's PageBreak AI security agent has been in full operation since January and found over 500 XSS vulnerabilities using Gemini models, reporting only after deterministic validators reproduce the exploit with a near-zero false-positive rate. This matters because it shows how AI can be constrained to produce actionable findings rather than noise, which is a persistent problem in automated security testing.

  3. DoorDash Cuts Grocery Reorder Latency from 16 to 2 Seconds with AI Agents

    InfoQ · 30 Oct 2026

    According to InfoQ, DoorDash cut the latency of its AI-powered grocery reorder flow from 16 seconds to 2 seconds by combining batch LLM inference, deterministic validation, and live product catalog resolution, which doubled shopping list views and increased order rate by approximately 34%. The shared agent platform provides orchestration, memory, model access, tracing, evaluation infrastructure, and rollout controls, which is the kind of infrastructure most teams end up building piecemeal.

  4. Netflix Treats GPU Reliability as a Distributed Systems Problem

    InfoQ · 30 Oct 2026

    According to InfoQ, Netflix built a GPU reliability platform on Kubernetes that achieved more than 99.95% GPU-node availability and increased job success from approximately 98% to more than 99.5% using layered health checks, automated remediation, and fault-tolerant training with checkpointing and elastic workers. This is a useful reminder that GPU workloads need the same reliability engineering rigor as any other distributed system, not just raw compute provisioning.
