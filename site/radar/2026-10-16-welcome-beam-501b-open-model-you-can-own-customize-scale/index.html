  1. Welcome Beam: a 501B open model you can own, customize, and scale

    Hugging Face · 16 Oct 2026

    According to Hugging Face: Beam by Reflection is a 501B-parameter mixture-of-experts (MoE) model with 23B parameters active per token, released under the Apache 2.0 license. The model has a context window of 1 million tokens and supports text input and output. It features 52 layers, 256 experts per MoE layer, and 8 experts routed per token. Checkpoint formats available include BF16, FP8, and NVFP4, with the BF16 checkpoint around 1 TB in size. Day-0 support is provided for transformers, SGLang, and vLLM, along with a Rust-based custom harness. The model supports five reasoning levels: "low", "medium" (default), "high", "xhigh", and "max". Reflection is offering $10,000 in Hub credits for the best projects built using Beam and shared on the Hugging Face Hub. Benchmark results show performance across BF16, FP8, and NVFP4 precisions on tasks like SWE Bench Pro and Terminal Bench.
