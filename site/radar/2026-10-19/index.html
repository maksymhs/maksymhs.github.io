  1. Pinterest Uses Event Time Watermarks to Finalize Petabyte Scale Data Partitions

    InfoQ · 19 Oct 2026

    Pinterest has implemented an event time-based partition finalization mechanism using Apache Flink and Apache Iceberg. This approach addresses the challenge of continuous Change Data Capture (CDC) ingestion, where data can arrive after a partition's wall clock interval has ended. The new mechanism uses Flink to measure event time progress and Iceberg metadata to publish a non-regressing finalization watermark. According to Pinterest, the platform supports petabyte-scale data and thousands of pipelines, with online changes typically available within 15 minutes to an hour. I would check how this mechanism handles late-arriving records and ensures data completeness without sacrificing freshness. The ability to derive a table-specific completeness signal and store it alongside the data is a significant advancement in managing large-scale data ingestion.
