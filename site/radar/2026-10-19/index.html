  1. Pinterest Uses Event Time Watermarks to Finalize Petabyte Scale Data Partitions

    InfoQ · 19 Oct 2026

    Pinterest has implemented an event time-based partition finalization mechanism for its database ingestion framework. This approach uses Apache Flink to measure event time progress and Apache Iceberg metadata to publish a non-regressing finalization watermark. According to InfoQ, this addresses a challenge in continuous Change Data Capture (CDC) ingestion where data can arrive after a partition's wall clock interval has ended. Pinterest's ingestion framework supports petabyte-scale data and thousands of pipelines, with online changes typically available within 15 minutes to an hour. This is crucial for backend teams dealing with large-scale data ingestion and real-time analytics. I would check how this mechanism integrates with existing data pipelines and whether it can handle the specific latency requirements of our systems. At Openbank, we have experience with event-driven communication on AWS SQS, and this approach could potentially enhance our data ingestion processes by providing more reliable and timely data availability.
