  1. Pinterest Uses Event Time Watermarks to Finalize Petabyte Scale Data Partitions

    InfoQ · 19 Oct 2026

    Pinterest has implemented an event time-based partition finalization mechanism using Apache Flink and Apache Iceberg. This approach addresses challenges in continuous Change Data Capture (CDC) ingestion where data can arrive after a partition's wall clock interval has ended. The system measures event time progress and publishes a non-regressing finalization watermark, ensuring that downstream jobs can safely consume data. According to InfoQ, this mechanism supports petabyte-scale data and thousands of pipelines, with online changes typically available within 15 minutes to an hour. This is particularly relevant for backend teams dealing with large-scale data ingestion and real-time analytics.
