Azure AI Gateway now generally available

28 Nov 2026 · 4 picks

Microsoft's Azure AI Gateway is now generally available, supporting multiple AI models and offering a cost-based model router.

  1. Azure AI Gateway Reaches General Availability as a Standalone Service

    InfoQ · 28 Nov 2026

    Microsoft has made Azure AI Gateway generally available as a standalone Azure service, expanding from its previous public preview as a dedicated tier of Azure API Management. According to InfoQ, the service is now available in 17 regions, with pricing starting at $500 per gateway per month for up to 10 million requests, plus $20 for each additional million, beginning January 1, 2027. Azure AI Gateway supports a wide range of AI models, including Microsoft Foundry, Azure OpenAI, OpenAI, Anthropic, Amazon Bedrock, and Google Vertex AI. The service includes a cost- and quality-based Model Router, which remains in preview. I would consider the integration capabilities with existing systems and the reliability of the Model Router before adopting it for production. The preview features for Private Link, VNet integration, and threat protection are also worth watching as they mature.

  2. How Clay Builds GTM Agents — Jeff Barg, Head of AI

    Latent Space · 26 Nov 2026

    Clay's Head of AI, Jeff Barg, discusses the company's approach to building go-to-market agents. According to Latent Space, Clay acquired Avenue, an ops alerting startup, and has since integrated its capabilities into their agent and outside harnesses. The company's focus on agentic AI tools is notable.

  3. Meta Brings Code Review Auto-Approval More Mainstream with PyTorch GreenLight

    InfoQ · 27 Nov 2026

    Meta has introduced PyTorch GreenLight, an AI reviewer that auto-approves pull requests from PyTorch maintainers. According to Meta Engineering, the system has significantly increased the number of lines of code per human-landed diff and the number of diffs per developer per month. The reliability and accuracy of the auto-approval process would be crucial to verify before adopting it in a critical project.

  4. Building Token Budgets for Spring AI: The Problems I Didn't Expect

    Foojay · 27 Nov 2026

    The challenges of managing token budgets for Spring AI are discussed in a recent article. According to Foojay, the author created a tool called Token Allowance for Spring Boot to manage token and dollar budgets for Spring AI ChatClient calls. This tool could be useful for teams looking to optimize their AI usage costs.
