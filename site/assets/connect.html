MCP setup for developers

If you already use connectors, add my profile as a public MCP server. Your assistant can then read my experience and my daily radar, check my fit against a job description and even send me a message. It also adds ready-made prompts: /talk_to_maksym (answers as me, in the first person), /ask_my_cv, /evaluate_fit and /interview_plan. No sign-up, no API key.

https://api.maksym.site/mcp

In Claude (web or desktop): Settings → Connectors → Add custom connector, then paste the URL above. Availability of custom connectors depends on your plan.

~/.cursor/mcp.json

{
    "mcpServers": {
      "maksym": { "url": "https://api.maksym.site/mcp" }
    }
  }

~/.codeium/windsurf/mcp_config.json

{
    "mcpServers": {
      "maksym": { "serverUrl": "https://api.maksym.site/mcp" }
    }
  }

.vscode/mcp.json

{
    "servers": {
      "maksym": { "type": "http", "url": "https://api.maksym.site/mcp" }
    }
  }

Run this in a terminal with Claude Code installed:

claude mcp add --transport http maksym https://api.maksym.site/mcp

Then try /talk_to_maksym, or ask: “Here's our job description. Is Maksym a good fit, and what would you ask him in an interview?”
